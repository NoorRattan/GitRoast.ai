# Architecture Decisions

This file records intentional deviations from the original planning documents so contributors can distinguish current product decisions from missing work.

## Deterministic Local Roast Engine

The local content engine in `app/services/roast_engine.py` supersedes the earlier Claude-based roast plan. GitRoast does not claim that roast prose is generated by an LLM. Scoring and findings are deterministic, roast copy is assembled from the checked-in line bank, and the admin queue is used to improve that line bank.

This removes per-audit model cost, prompt-injection exposure, and nondeterministic output. The abandoned Claude-output fine-tuning plan is not part of the current roadmap.

## Next.js 15

The frontend intentionally runs Next.js 15.5 rather than the original Next.js 14 target. The exact supported version is pinned in `package.json` and verified by CI.

## Imperative Three.js

The score field intentionally uses Three.js directly rather than React Three Fiber. It is one isolated visualization with explicit resource disposal, reduced-motion fallback, pointer parallax, drag rotation, and entrance animation. Avoid adding React Three Fiber unless multiple composable scenes make its runtime and bundle cost worthwhile.

## Deployment Domains

The public frontend and card worker intentionally use Cloudflare workers.dev origins. No custom domain is configured. Render automatic deploys are disabled; the main-branch CI workflow deploys the gateway, frontend, card Worker, then triggers the Render deploy hook when the production environment contains the required secrets.
